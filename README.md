# India GCC Location & Workforce Expansion Analytics

An end-to-end data analytics project evaluating major Indian cities for Global Capability Center (GCC) expansion and workforce strategy.

## Business Problem

Which Indian city provides the strongest opportunity for establishing or expanding a GCC, and which technology workforce capabilities should organizations prioritize?

## Target Locations

- Bengaluru
- Hyderabad
- Pune
- Chennai
- Delhi NCR
- Mumbai

## Workforce Categories

- Data Engineering

- Software Engineering
- Cloud / DevOps
- Cybersecurity
